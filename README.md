# Ballpark Day of Faith static site

This repository powers [ballparkdayoffaith.com](https://ballparkdayoffaith.com) through Netlify continuous deployment.

## Current site

- Evergreen Ballpark Day of Faith homepage
- 2027 event placeholder pending confirmed date, schedule and tickets
- About, Experience, Stories, News, Donate, Volunteer, Sponsor and Postgame Resources pages
- Migrated blog archive with 16 articles
- Netlify volunteer-interest form

The expired Lambeau Leap of Faith promotion is intentionally excluded from the live site.

## Publishing

Edits committed to the GitHub `main` branch automatically deploy to Netlify.
